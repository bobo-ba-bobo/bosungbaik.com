## 1. 디자인 철학

**한 마디로: "절제된 깔끔함"**

- 군더더기 없는 미니멀 디자인
- 콘텐츠가 주인공이고, 디자인은 콘텐츠를 방해하지 않는다
- 과한 인터랙션보다 정돈된 정적 레이아웃을 선호
- 단, 특정 페이지에서는 의도적으로 "조금 튀는" 포인트를 줄 수 있음

## 2. 색상 팔레트

**3색 원칙**: 블랙, 그레이, 화이트만 사용

회색은 배경에 따라 다른 값을 쓴다 — 흰 배경에서는 어둡게, 검은 배경에서는 밝게.

#### 흰 배경 (On White)
| 용도 | Hex |
|------|-----|
| 배경 | `#FFFFFF` |
| 본문 텍스트 | `#000000` |
| 보조 텍스트 / 호버 | `#616161` |
| 3차 텍스트 | `#7A7A7A` |
| 뮤트 / 캡션 | `#858585` |

#### 검은 배경 (On Black)
| 용도 | Hex |
|------|-----|
| 배경 | `#000000` |
| 본문 텍스트 | `#FFFFFF` |
| 보조 텍스트 | `#E6E6E6` |
| 3차 텍스트 | `#BFBFBF` |
| 뮤트 / 캡션 | `#9E9E9E` |

### 흑백 반전 규칙
- 특정 섹션이나 영역에서 배경을 블랙, 텍스트를 화이트로 반전 가능
- 반전은 시각적 구분과 강조 목적으로 사용
- 반전 영역과 기본 영역의 대비가 콘텐츠 계층을 만든다

### 금지 사항
- 컬러 액센트 없음 (파란색 링크, 빨간색 경고 등 불가)
- 그라디언트 없음
- 섀도우는 최소한으로만 (사용 시 흑/회색 계열)

## 3. 타이포그래피

### 폰트
- **영문**: Inter
- **한글**: Pretendard

### 계층 구조
| 레벨 | 용도 | 굵기 | 크기 (참고) |
|------|------|------|------------|
| H1 | 페이지 제목 | Medium~Bold | 크게 |
| H2 | 섹션 제목 | Medium | 중간 |
| Body | 본문 | Regular~Light | 15~16px |
| Caption | 부가 정보 | ExtraLight~Light | 작게 |

### 타이포그래피 원칙
- 텍스트 자체가 네비게이션이자 디자인 요소
- 행간(line-height): 1.2~1.3em, 여유 있게
- 자간(letter-spacing): 기본값(0px) 유지
- 텍스트 크기 대비로 정보 우선순위를 표현

## 4. 레이아웃

### 구조
- 단일 열(single-column) 중심의 선형 레이아웃
- 콘텐츠가 위에서 아래로 자연스럽게 흐르는 구성
- Flexbox 기반

### 컨테이너 & 반응형
| 디바이스 | 너비 | 좌우 여백 |
|---------|------|----------|
| 데스크톱 | 1200px | 120px |
| 태블릿 | 810px | 적절히 축소 |
| 모바일 | 390px | 40px |

### 여백(Spacing)
- 섹션 간 여백을 넉넉하게 (100px 이상급의 호흡감)
- 여백이 곧 디자인 - 빈 공간을 두려워하지 않는다
- 섹션 내부 요소 간격: 10~30px

---

## 5. 인터랙션 & 애니메이션

### 기본 원칙
- **과하지 않게**: 불필요한 인터랙션은 배제
- 호버 효과 정도가 적정선

### 허용되는 인터랙션
- 링크 호버 시 색상 변화 (블랙 → 그레이) + 언더라인
- 색상 전환 애니메이션 (0.3~0.4초, ease 또는 cubic-bezier)
- 페이지 전환 시 부드러운 fade

### 특정 페이지 예외
- 일부 페이지에서는 의도적으로 동적인 요소를 넣을 수 있음
- 예: 스크롤 애니메이션, 마우스 추적 효과, 텍스트 모션 등
- 단, 전체 사이트 톤을 벗어나지 않는 범위 내에서

### 피해야 할 것
- 과도한 패럴랙스 스크롤
- 로딩 시간을 늘리는 무거운 애니메이션
- 사용자 행동을 방해하는 모달/팝업
- 자동 재생 미디어

## 8. 현재 사이트 디자인 현황

### 잘 되어 있는 것
- 흑백 색상 팔레트 (블랙/화이트/그레이 원칙에 부합)
- Inter + Pretendard 폰트 조합
- 호버 시 부드러운 색상 전환 (0.4초)
- 3단계 반응형 브레이크포인트

### 현재 CSS 값 (참고)
```
배경:              #FFFFFF
텍스트:            #000000
보조 텍스트:       #616161  (on white)
뮤트 텍스트:       #858585  (on white)
반전 보조 텍스트:  #bfbfbf  (on black)
반전 뮤트 텍스트:  #9e9e9e  (on black)
여백:              데스크톱 120px 좌우 / 모바일 40px
폰트:              Inter, Pretendard
호버 전환:         0.3s ease
```

## 9. 디자인 원칙 요약

1. **흑/백/회색만 쓴다** - 색상에서 오는 깔끔함이 핵심
2. **여백을 아끼지 않는다** - 빈 공간이 고급스러움을 만든다
3. **텍스트가 디자인이다** - 폰트와 크기 대비로 계층을 만든다
4. **인터랙션은 절제한다** - 호버 정도가 적정, 특별한 페이지에서만 예외
5. **흑백 반전은 의도적으로** - 섹션 구분과 시각적 리듬을 위해 사용
6. **itsdpark.com을 기준점으로** - 극도의 미니멀 + 프로페셔널이 지향점
