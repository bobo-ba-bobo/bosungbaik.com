Cloud Sync Setup

One-time setup per browser. Data syncs across all browsers/devices via your private GitHub gist.

  1. Create a secret gist at gist.github.com. Filename: finance.json, content: {}. Copy the gist ID from the URL.
  2. Create a token at github.com/settings/tokens/new. Note: "finance". Expiration: 1 year or no expiration. Scope: check only gist. Copy the ghp_... token.
